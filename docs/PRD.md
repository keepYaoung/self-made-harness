# PRD — Clipdoggy

> 출처: ClipDoggy 레포 `README.md`, `docs/PRODUCT_STRATEGY.md`, `docs/research-mac-clipboard-ui.md` (2026-09 기준, 버전 1.1.1)

## 1. 한 줄 정의
Mac과 Android를 오가며 일하는 사람이 **복사는 한 번, 어디서든 붙여넣기** 할 수 있게 해 주는 — 종단간 암호화 클라우드 동기화가 붙은 스마트 클립보드 매니저.

## 2. 핵심 사용자 (페르소나)
**맥북 + 안드로이드폰을 같이 쓰는 실무자** (예: 스타트업 PM/디자이너, 20–30대)
- 상황: 폰에서 받은 인증번호·링크·사진을 맥으로, 맥에서 쓴 주소·문구를 폰으로 옮길 일이 하루 수십 번
- 불편: Apple 생태계 밖이라 유니버설 클립보드가 안 되고, 카톡 "나에게 보내기"나 메일로 우회한다. 맥 기본 클립보드는 기록도 없다.
- 기대: 설치·연결이 1분 안에 끝나고, 내용이 서버에 평문으로 남지 않을 것

## 3. 사용 시나리오
1. **폰 → 맥 텍스트**: 폰에서 인증번호/주소를 복사 → 맥 메뉴바 패널에 즉시 도착 → ⌘1로 바로 붙여넣기
2. **맥 → 폰 이미지**: 맥에서 스크린샷 복사 → 안드로이드 이미지 탭에 도착 → 저장하거나 메신저로 공유 (이미지 3MB / 파일 10MB 상한)
3. **단일 기기 히스토리**: 기기가 하나여도 — 어제 복사한 링크를 검색해서 찾고, 자주 쓰는 문구는 핀 고정

## 4. 화면 목록
- **온보딩** — Splash → Welcome → 알림 권한 → Home (양끝 dissolve, 중간 좌→우 슬라이드)
- **홈 / 클립 히스토리** — 받은·보낸 텍스트 카드 리스트 + 이미지 그리드 (라벨: 받음·보냄·복사·핀·실패)
- **클립 미리보기** — 파스텔 상단 블록 + 본문, 복사/핀/삭제
- **이메일로 연결하기 (클라우드 계정)** — Google 로그인, 연결된 기기 목록·관리
- **Mac 메뉴바 패널** — 상단 슬라이드 다운, 좌 이미지 스트립 / 우 텍스트 리스트, 키보드 완결 흐름

## 5. 디자인 가드레일
**Do**
- 복사→도착까지 한 동작. 상태(받음/보냄/실패)는 색 라벨 + 토스트로 즉시 알린다
- 키보드만으로 끝나는 흐름 (↑↓←→ · Enter · Esc · ⌘1–9)
- 단일 기기에서도 쓸모 있는 화면을 먼저 — 연결은 "더 좋아지는" 옵션
- 6개 언어(en/ko/ja/zh-CN/es/hi)에서 문구가 넘치지 않게 여유 폭 확보
- 프라이버시(E2EE)를 신뢰 신호로 짧게 노출

**Don't**
- 구독 강제·페이월로 핵심 동기화를 막지 않는다
- 연결 전 빈 화면을 "쓸모없음"으로 두지 않는다 (빈 상태에 다음 행동 제시)
- 플랫폼 관례를 깨지 않는다 — Mac은 메뉴바/단축키, Android는 알림·위젯
- 주요 CTA를 여러 스타일로 만들지 않는다 — `LayeredCtaButton` 하나로 색·치수만 바꾼다

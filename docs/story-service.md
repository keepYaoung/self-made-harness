# 서비스 맥락 — Clipdoggy

> 출처: docs/PRD.md (ClipDoggy 1.1.1). [사용자 확인]은 PRD 밖에서 사용자가 직접 알려 준 내용.

## 유저스토리
1. 맥북과 안드로이드폰을 같이 쓰는 실무자가 폰에서 복사한 인증번호·주소를 맥 메뉴바 패널에서 받아 ⌘1로 붙여넣는다.
2. 실무자가 맥에서 복사한 스크린샷을 안드로이드 이미지 탭에서 받아 저장하거나 메신저로 공유한다 (이미지 3MB / 파일 10MB 상한).
3. 기기가 하나인 사용자가 어제 복사한 링크를 검색해 찾고, 자주 쓰는 문구를 핀 고정한다.
4. 사용자가 Google 로그인으로 클라우드 계정을 연결하고, 연결된 기기 목록을 관리한다.
5. 맥 사용자가 메뉴바 패널 흐름을 키보드만으로 끝낸다 (↑↓←→ · Enter · Esc · ⌘1–9).

## 플랫폼 범위
- 출시: Mac · Android — 게이트 플랫폼 매트릭스 필수 대상
- [사용자 확인] iOS · Windows — 베타 존재, 미출시. 장기 지원 예정. 게이트 필수 대상 아님

## 어기면 안 되는 것 (판정 기준 — 작업 흐름 재료 아님)
- **A. 클립 내용이 서버에 평문으로 남지 않는다** (PRD §1, §2)
- **B. 구독 강제·페이월로 핵심 동기화를 막지 않는다** (PRD §5 Don't)

## 하네스 적용 범위
- 일반 UX/UI 디자인 (산출물: Figma 프레임 + 스펙 md) · 스토어 스크린샷 · 릴리즈 QA 시트
- 이벤트 시트 (하네스 구현됨 · 손작업 흐름은 story-work 에 아직 없음)
- **다국어 패치노트** (트랙 B 새 도메인, 2026-09-29)

## 도메인: 다국어 패치노트
> PRD 에 패치노트 절은 없다. PRD 에서 온 것과 `[문서 확인]`(앱 리포 문서) 을 나눠 적는다.

### 유저스토리
1. 맥북과 안드로이드폰을 같이 쓰는 실무자가 폰에서 복사한 내용을 맥에서 바로 붙여넣는다. (PRD §3-1)
2. 실무자가 맥에서 복사한 이미지를 안드로이드에서 받아 저장하거나 공유한다. (PRD §3-2)
3. 기기가 하나인 사용자가 지난 기록을 검색하고, 자주 쓰는 문구를 핀 고정한다. (PRD §3-3)
4. 사용자가 이 서비스를 6개 언어(en/ko/ja/zh-CN/es/hi) 중 하나로 쓴다. (PRD §5 Do)
5. `[문서 확인]` 사용자가 스토어에서 이번 업데이트 내용을 자기 언어로 읽는다. (앱 리포 `docs/release-notes-1.1.1.md` §2)

### 어기면 안 되는 것 — 이 도메인에서 걸리는 모습
- **A. 평문 저장 금지** → 패치노트가 "서버에 저장·백업" 처럼 클립 내용이 서버에 남는다고 읽히면 안 된다
- **B. 페이월 금지** → 동기화 개선 항목에 "Pro 전용 · 유료 · 구독" 같은 조건을 붙이면 안 된다
- `[문서 확인]` 현재 기능만 말한다 — 폐기된 BLE·PIN·페어링 문구 금지 (`docs/design.md` Voice & Copy). PRD 밖 규칙이라 ★ 가 아니라 일반 게이트 후보

# 서비스 맥락 — Clipdoggy

> 출처: docs/PRD.md (ClipDoggy 1.1.1). [사용자 확인]은 PRD 밖에서 사용자가 직접 알려 준 내용.

## 유저스토리
1. 맥북과 안드로이드폰을 같이 쓰는 실무자가 폰에서 복사한 인증번호·주소를 맥 메뉴바 패널에서 받아 ⌘1로 붙여넣는다.
2. 실무자가 맥에서 복사한 스크린샷을 안드로이드 이미지 탭에서 받아 저장하거나 메신저로 공유한다 (이미지 3MB / 파일 10MB 상한).
3. 기기가 하나인 사용자가 어제 복사한 링크를 검색해 찾고, 자주 쓰는 문구를 핀 고정한다.
4. 사용자가 Google 로그인으로 클라우드 계정을 연결하고, 연결된 기기 목록을 관리한다.
5. 맥 사용자가 메뉴바 패널 흐름을 키보드만으로 끝낸다 (↑↓←→ · Enter · Esc · ⌘1–9).

## 플랫폼 범위
- 출시: Mac · Android — 게이트 플랫폼 매트릭스 필수 대상
- [사용자 확인] iOS · Windows — 베타 존재, 미출시. 장기 지원 예정. 게이트 필수 대상 아님

## 어기면 안 되는 것 (판정 기준 — 작업 흐름 재료 아님)
- **A. 클립 내용이 서버에 평문으로 남지 않는다** (PRD §1, §2)
- **B. 구독 강제·페이월로 핵심 동기화를 막지 않는다** (PRD §5 Don't)

## 공통 — 정본 방향
- 모든 문서의 정본은 **리포 안 md**. 노션은 md에서 가져가 인터랙션(체크)하며 진행하는 파생본
- 제품의 최종 SOT는 **코드**

## W1. UX/UI 화면 디자인 (1.0.7까지)
1. 나는 노션 PRD 또는 버전 PRD 문서를 읽는다.
2. 나는 Mobbin·UI Bowl에서 화면 레퍼런스를 리서치한다.
3. 나는 비슷한 동종 앱을 리서치한다.
4. 나는 초안 디자인을 만든다.
5. 나는 Figma에서 초안을 보강한다.
6. 나와 Claude Code가 보강한 Figma를 기반으로 코드를 만든다. [넘김 → Claude Code]
7. 나는 디자인과 기능을 확인한다. [멈칫 ×2]

- [x] 2회 이상 반복 — 1.0.4 출시 때 AOS 5장 × 3언어, Mac 3장 × 3언어. UI·기능이 바뀔 때마다 다시 필요
- [x] 품질이 들쭉날쭉 — 폰 목업 각도·카피 톤·언어별 줄바꿈이 매번 다름. 기능이 바뀌어도 옛 문구가 남음 ("No Servers. No Cloud", "Pair with Code")

## 입력
- 현재 버전의 실제 앱 화면 캡처 (에뮬레이터/시뮬레이터 또는 실기기)
- 이번 버전에서 강조할 기능 3–5개 (`docs/release-notes-*.md`)
- `design.md` (색·폰트·Do/Don't), `i18n/strings.csv` (앱 내 문구)

## 단계
1. **메시지 정하기** — 장당 한 기능, 헤드라인 1줄 + 서브 1줄. 현재 기능과 어긋나는 문구 금지
2. **화면 캡처** — 데모 데이터로 채운 깨끗한 상태 (시각 09:41, 풀 배터리, 개인정보 없음)
3. **레이아웃** — 헤드라인 상단, 기기 목업 하단. 배경 `#FDFDFD`, 텍스트 `#333333`, 폰트 Pretendard JP / 영문 헤드라인 Eudoxus Sans
4. **다국어 렌더** — 같은 템플릿에 언어별 카피만 교체. 가장 긴 언어 기준으로 폭 확인
5. **검수 게이트** (아래) 통과 후 `design-resource/` 에 저장

## 검수 게이트
- [ ] 캡처 속 UI가 **현재 버전**과 같다 (로고 워드마크 "Clipdoggy", 탭 구성)
- [ ] 카피가 현재 기능과 일치 — 클라우드 동기화·E2EE 기준. BLE/Wi‑Fi/PIN 페어링 문구 없음
- [ ] 규격(픽셀·장수·파일명)이 표와 일치
- [ ] 모든 언어에서 헤드라인이 2줄 이내, 잘림·겹침 없음
- [ ] 실제 개인정보(이메일·기기명·클립 내용) 없음
- [ ] 장 순서 = 기능 우선순위 (1장이 핵심 가치)

## 품질이 흔들리던 지점
- 기능 변경 후 옛 카피가 그대로 남음 → 게이트 2번
- 언어마다 수작업으로 줄바꿈 → 템플릿 한 벌 + 카피 표로 일괄 렌더
